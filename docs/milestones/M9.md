# M9 — Portfolio polish

## Goal
The game looks and sounds finished for a first-time visitor: a loading screen, a title screen, a short tutorial, music, juice, an options menu, README and credits, and a deploy path.

## Built
- **Loading screen** (static HTML in `index.html`, fades out when the city and physics are ready).
- **Title screen** (Play / Options / Credits, key reminder, best clear and skill count). The game is paused behind it and the camera drifts slowly. Enter or the Play button starts. Automated browsers skip it unless the URL has `?title`.
- **First-flight tips** (`src/gameplay/tutorial.ts`, data in `src/data/tutorial.ts`): walk, flap, dive, grab, poop, one tip at a time, each ticks off when you do it. **T** skips, and the options menu can turn them back on.
- **Options menu (O)**: volume, music, sound effects, mouse look, screen shake; saved in localStorage (`src/core/options.ts`, separate from the game save) and mirrored in the tuning object / debug panel. Any open panel (title, options, skills, credits) pauses the game.
- **Music** (`src/core/music.ts`, `src/gameplay/musicDirector.ts`, `src/data/music.ts`): public-domain / CC0 recordings, three tiers (calm, playful, chaos) chosen from the heat tier and the finale, crossfaded, going up at once and down after a delay. M mutes it. Credits in README, in-game credits (C) and `data/raw/SOURCES.md`.
- **Juice**: camera shake on hard landings, bonks, spray/swat/net hits and crashes (scaled by the options slider), feather puffs when hit, dust on hard landings, confetti on quest wins.
- **Docs and deploy**: README architecture notes and credits; `.github/workflows/deploy.yml` publishes `dist/` to GitHub Pages when `main` changes (enable Pages with source "GitHub Actions" once).
- Tests: options sanitising/storage, tutorial state machine, music director; browser tests for title/pause/tips/options persistence and the music crossfade.

## Notes
- `docs/media/lokki-flight.gif` is a rough software-rendered capture. A real GIF recorded on your machine (e.g. ScreenToGif) will look much better; drop it in over the same name.
- Public-domain recording status was read from Wikimedia Commons metadata; worth a last look at each Commons file page before going public (see `data/raw/SOURCES.md`).
- The bottle-smash browser test is timing-sensitive under full-suite load; it passes when run alone.

## Exit criteria
- [ ] First launch: loading screen, title screen, tips; all feel clear and skippable
- [ ] Music follows the action and crossfades without jarring cuts
- [ ] Options persist across reloads; panels pause the game
- [ ] Screen shake and particles add punch without making you dizzy
- [ ] `npm run build` output plays from any static host (try Pages)
- [ ] README and credits are accurate
