# M59 — Mechanic gating

Branch: `m59-gating` (stacked on `m58-arcs-plan`). Plan: `docs/design/arcs.md`.

## Built
- `src/gameplay/mechanics.ts`: the ladder (17 mechanics, each with the arc.stage that introduces it and a tip), `parseGate`, `isUnlocked`, `introducedAt`, `unlockedAt`, `switchMech`.
- `LevelDef.gate?: { arc, stage }`: a level with a gate has exactly the mechanics of that stage and the stages before it; **no gate = everything** (so today's levels, the sandbox and the Playground are unchanged). `?gate=1.3` in the address overrides it for testing.
- Locked verbs do nothing: poop (F), toss (Q), tug (ground E), honk (tap T; a soft "Not yet" the first time), taunt (hold T), hiding and BOO, switches (by effect: alarm and sprinkler, jukebox and bell, tablecloth, domino, captain's cap), slip puddles, contagion, slam, wing gust, the dog's honk call, cannonball.
- Skills are unaffected: they stay unlocked once earned.

## Not in this milestone
- Greying out locked buttons on touch and in the controls screen, and per-mechanic first-use tips: they belong with the stage framework (M60), which knows the current stage.
- No level has a gate yet: the stages that use it are built from M61.

## Tests
`tests/unit/mechanics.test.ts`, NPC gates in `tests/unit/contagion.test.ts`, `tests/smoke/gating.spec.ts` (gate 1.1 locks the jukebox and the verbs, 1.5 opens them, no gate opens everything).

## Playtest notes
Try `?level=jukebox-hero&gate=1.1`: the jukebox does not react; `&gate=1.4` opens it.
