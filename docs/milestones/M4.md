# M4 — Interaction core

## Goal
The player can invent gags with a few props.

## Built
- **Physics (Rapier)** `src/physics/physics.ts`: fixed 60 Hz step inside the sim loop; ground slab; buildings and landmarks become one static triangle-mesh collider built from the same extruded data as the visuals; the gull has a kinematic body, so **dives and shoves push props**. Collision layers keep carried props from colliding with anything.
- **Props** (data-driven, `src/data/props.ts`): ice cream, fried vendace, cinnamon bun, student cap, top hat, bottle, litter bin, crate, chair. Each has tags (`edible`, `shiny`, `noisy`, `throwable`, `fragile`, `heavy`, `hat`, `container`, `stackable`), mass and collision shape. Visuals are built from primitives (`src/world/propMeshes.ts`).
- **Grab / carry / drop / toss** (`E`, `Q`): the nearest liftable prop in a cone in front of the beak is grabbed and held in the beak. Heavy things (> `interaction.carryMax`, 1 kg) say "too heavy" and can only be shoved. Carrying weakens flapping (`interaction.carryPenalty`). A context prompt at the bottom of the screen says what `E` does.
- **Poop** (`F` or left click): a ballistic drop that inherits part of the gull's velocity and **drifts with the wind**. The aim reticle (brown ring) shows the predicted landing spot using the same physics. Cooldown bar next to the stamina bar. It splats on ground, roofs and walls (decals from a recycled pool, up to `poop.maxDecals`) and on props (a blob sticks to the prop and it counts as `dirty`).
- **Gags** from tags: bottles (`fragile`) shatter when they hit something fast; bins, chairs (`noisy`) clatter; bins and chair stacks announce when they get tipped over. Placeholder sounds: pop, splat, clatter, crash (synthesised).
- **Sandbox** at (0, -82), north of the market tents: food, hats, bottles on the ground, crates "tables" with ice cream and hats on top, two bins, a 4-chair stack and a crate pyramid. `R` resets the gull, all props (including broken ones) and wipes splats.
- Pure logic with unit tests: prop data, grab picking, poop ballistics (gravity, wind, wall/roof normals, prop hits), impact rules. Physics tests run the real Rapier engine in Node (settling, static mesh, carry/toss, shatter, shove, poop on props).

## Notes / deviations
- Rapier (`@dimforge/rapier3d-compat`, as decided in the plan) is a **big** dependency: its WASM is a separate lazily loaded chunk of ~4.3 MB (~1.7 MB gzipped). Fine locally; for hosting later we can switch to the non-compat build or compress.
- The gull itself is still driven by its own flight collision (M1/M3), not by Rapier. Props are not solid for the gull: it gets pushed through, props get shoved aside. (Landing on a bin as a perch is not possible yet.)
- Water is ground for props too: they float on it.
- Prop meshes are not merged/instanced yet: ~100 draw calls in the sandbox view (still under the 200 budget; culled when out of view).
- Poop is a particle (not a Rapier body); props are Rapier bodies.
- `E` grabs from any state, including mid-air.

## Exit criteria (for the user)
- [x] You can grab, carry, drop and toss the light props, and heavy ones refuse
- [x] Poop is aimable (reticle), drifts with wind, splats on ground/walls/props
- [x] You can invent a gag in the sandbox (e.g. drop a bottle from height, dive into a bin, poop on a hat, carry an ice cream to the other side of the square)
- [x] Nothing falls through the world or flies off weirdly; fps still fine

## Playtest notes
User: grab/carry/toss works, poop works, gags work, fps still good. **Poop is not the easiest to aim** (moving gull = moving landing spot; reticle only shows the ground spot). Idea for M5+: light aim assist toward NPCs/props near the predicted spot (like the dive assist), and slowing down/flaring helps. M4 passed.
