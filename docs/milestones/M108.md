# M108 — Real city R1: buildings styled by their real era and material

Research and plan: `docs/design/realistic-city-research.md`.

## Decisions (2026-11-21)
- **Look:** keep the pastel look for now. Keep a photorealistic mode possible later, so the source data goes into the repo.
- **Downloads:** the user downloads the reality mesh (`data/raw/mesh/README.md`).
- **OpenStreetMap:** not used for now; the option stays open.

## Built

### Real-city data snapshot
`scripts/fetch-real.ts`, run with `npm run data:fetch-real`, or `-- register`, `-- ortho` or `-- citygml` for one part.
- **`data/raw/register.json`:** the register fields we used to drop, for all 521 buildings in the box: facade material, completion date, frame material, use and heating. 39 kB.
- **`data/raw/ortho/`:** the City's 2025 orthophoto of the 1.2 km box at 0.3 m per pixel, in 4 tiles (1.9 MB). Kept for real roof colours (R3) and a future photo mode.
- **`data/raw/citygml/`:**
  - The LoD2 buildings (real roofs) from the City's 3D WFS, fetched in pages with retries.
  - **Not fetched yet:** the service answered every request with "overloaded, retry later" all session. Rerun `npm run data:fetch-real -- citygml` later; pages already saved are skipped.
  - Or download the CityGML map sheets at <https://kartta.hel.fi/3d/>.
- **`data/raw/mesh/`:** the slot for the reality mesh, with download instructions. `.gitattributes` puts it in Git LFS.
- `data/raw/SOURCES.md` and the README credits are updated. Everything is CC BY 4.0, © City of Helsinki, like the data we already had.

### Style from the register (R1)
- **Map data:** `scripts/build-world.ts` gives each building an era code and a facade code (`e`, `f` in `data/generated/kauppatori.json`). 312 of the 397 buildings have an era and 254 a facade material. Everything else in the generated file is byte-for-byte unchanged.
- **`src/world/buildingStyle.ts`** (pure). The era comes from the completion year:

  | Era | Years | Walls | Roof | Windows | Turrets | Balconies |
  |---|---|---|---|---|---|---|
  | Empire | before 1870 | yellow and cream render | copper-green or slate, pitched where the footprint allows | classic | none | none |
  | Historicism | 1870–1899 | warm render | slate | tall arched | sometimes | |
  | Jugend | 1900–1919 | earth tones | slate or terracotta | | often | |
  | Classicism | 1920s | pale | | regular | | |
  | Functionalism | 1930–1949 | white | flat, no mansard | strip | | more |
  | Modern | 1950 onwards | white | flat | banded | | |

  The facade material picks the colour family:
  - brick: soft brick reds
  - stone: warm granite beige
  - concrete: pale concrete
  - glass: pale blue, with strip windows
  - metal: blue-grey, flat roof
  - wood: ochre
  - render: keeps the era's colours
- **City builder** (`src/world/city.ts`): uses the kit for wall and roof colours, pitched/flat/mansard, the main window style, turrets and balconies.
  - Buildings with no register data, and the hand-styled landmarks, keep the old rules.
  - `tuning.render.realStyle`: 1 on, 0 the old district rules. It is read when the city is built, so changing it needs a reload.
- **Small additions:** `pitchedFits` (can this footprint carry a pitched roof), a style argument for `windowPlan`, and a chance argument for `balconies`.

## Tests
- `tests/unit/buildingStyle.test.ts`:
  - dates to eras, at the boundaries;
  - facade codes;
  - era rules (Empire pitched and plain, functionalism flat with strip windows, Jugend towers);
  - material colour families (brick warm, stone grey-ish);
  - the builders take the kit;
  - over 70% of the map's buildings have an era from the snapshot.
- `tests/smoke/real-city.spec.ts` takes aerial views of the market front, Senate Square and towards Katajanokka. It names the files from `SHOT=before|after`, and both sets are committed in `tests/__screenshots__/real-city-*-{before,after}.png`.
- Draw calls are unchanged (the style only changes colours and shapes inside the merged chunk meshes).

## What it looks like
- **Market front:** reads as Empire yellow and cream. The functionalist blocks lose their mansards and get strip windows.
- **Brick blocks:** stand out in brick red.
- **Stone-faced Jugend buildings:** turn granite beige with towers.
- **Overall:** the city is still pastel, but no longer randomly mint and lilac.

## Next (not started)

## Known issues
- **Missing data:** buildings without register data (85 of 397) still use the district palettes, so a few blocks keep the old random colours.
- **Facade codes:** taken from the national building register code list. To be confirmed against the City's field documentation; code 7 "other" is treated as rendered plaster.
