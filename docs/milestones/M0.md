# M0 — Foundations

## Goal
A running skeleton to build on.

## Built
Vite + TS + ESLint + Vitest; fixed 60 Hz timestep with render interpolation; keyboard/mouse input (optional pointer lock); event bus + asset cache; capsule gull on pastel ground with sky gradient and fog; third-person lag camera; debug overlay (FPS, tuning sliders, Copy tuning as JSON); Playwright smoke test.

## Exit criteria
- [ ] `npm run dev` shows the capsule moving smoothly at 60 fps
- [ ] `npm run build` + `npm run preview` works from `dist/`
- [ ] lint and tests pass
