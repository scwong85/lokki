# M3 — Helsinki blockout

## Goal
Recognisably Kauppatori from the air; stable 60 fps on integrated graphics; pipeline reproducible from `data/raw/`.

## Built
- **Data pipeline** (`scripts/`): `fetch-data.ts` (network, run once) → committed snapshot in `data/raw/` (+ `SOURCES.md`) → `build-world.ts` (offline, deterministic) → `data/generated/kauppatori.json` (~120 KB). Pure helpers in `scripts/lib/geo.ts` (projection to local metres, simplification, clipping, heights) are unit-tested; a test rebuilds the world from `data/raw/` and checks the output is byte-identical.
- **World:** ~400 real building footprints (courtyards included) extruded by floor count, pastel colours, terracotta/lilac roofs; streets, parks, land and water from city data; invisible walls at the 1.12 km map edge. 1 unit = 1 m, north = -Z, origin = Kauppatori.
- **Landmarks** (`data/landmarks.json`, `src/world/landmarks.ts`): Helsinki Cathedral (white body, stepped green dome, gold lantern), 27 orange market tents you can fly/walk under, a Suomenlinna-style ferry at the quay, the Havis Amanda statue and fountain, lamp posts along the quay. Landmark tops are perches.
- **Collision** (`src/world/collision.ts`): new `World` class with a spatial grid; sphere vs box and vs extruded polygon (footprints with holes, walls and roofs, raised canopies). Refactor of M1's box-only collision; flight logic only needed a signature change.
- **Rendering:** buildings merged into per-160 m chunks with vertex colours (frustum culling); flat land/street/park layers; one water plane. About 50-60 draw calls and 8-13k triangles (shown in the debug line, top-left).
- **Credits screen** (key `C`), README + `data/raw/SOURCES.md` attribution.
- 6 ice-cream dive targets remain (market aisles, ferry, cathedral lantern). `?greybox` loads the old M1 course.
- Fog is farther now (150-700 m) so you can see the city while flying high.

## Deviations from the plan (see also `data/raw/SOURCES.md`)
- The planned Helsinki 3D WFS endpoint 404s and the CityGML download only covers Kalasatama, so heights come from registry **floor counts** (floors x 3.2 m + 0.8 m), not CityGML LoD1/LoD2 roofs. Roofs are flat.
- OpenStreetMap was unreachable from the sandbox and unnecessary (the City's layers include streets, parks and coastline), so **no OSM/ODbL data** is used.
- `npm run data:*` scripts need Node >= 22.18 (native TypeScript). `earcut` is now a runtime dependency (3 KB).
- Gulls can land on water (treated as ground at y=0).
- Landmark positions are approximate and easy to nudge in `data/landmarks.json` (then `npm run data:build`).

## Exit criteria (for the user)
- [x] Recognisably Kauppatori from the air (cathedral, harbour, tents, ferry)
- [x] Stable 60 fps on your machine (check the debug line, top-left: fps / draw calls / triangles)
- [x] Flying and walking around buildings, courtyards and under the tents feels fine (no stuck spots, no falling through roofs)
- [x] Pipeline reproducible from `data/raw/` (tested)
