# M11 — Input layer + mobile landscape

## Goal
Play Lokki in a phone or tablet browser held sideways, with on-screen controls, without changing any gameplay code. Based on the spike in `docs/spikes/mobile-landscape.md`.

## How to try it on your phone
1. Phone and PC on the same Wi-Fi.
2. On the PC: `npm run build` then `npm run preview:lan`. Vite prints a "Network" address such as `http://192.168.1.23:4173/`. (Windows may ask to allow Node through the firewall: allow it for private networks.)
3. Open that address on the phone and turn it sideways.
4. Optional: "Add to Home Screen" (Safari share menu / Chrome menu), then start Lokki from the icon: it opens fullscreen in landscape without the browser bars. On Android, tapping Play also tries to go fullscreen and lock landscape on its own.

(`npm run dev:lan` works too, for live editing.) To try the touch layout on a PC, add `?touch` to the address; `?notouch` turns it off on a phone.

## Built
- **One input layer** (`src/core/input.ts`): keyboard and mouse as before, plus virtual sources: held keys (`setVirtual`), taps (`tap`), an analog stick (`setStick`) and look deltas (`addLook`). The game still only asks `Input` (key codes, axes, look), so the touch controls (and a future gamepad) need no gameplay changes.
- **Touch controls** (`src/ui/touchControls.ts`, maths in `src/core/touchMath.ts`):
  | Action | Touch |
  |---|---|
  | Walk / steer, flare | Left thumb anywhere in the left ~40%: a floating stick appears under it (analog). Pull back while flying to brake |
  | Look around | Drag on the right half |
  | Flap / hop | **Flap** (hold to keep flapping) |
  | Dive | **Dive** (hold; slide up/down to aim steeper/shallower, let go to swoop up) |
  | Grab / drop | Context button labelled with what it will do ("Grab cinnamon bun", "Drop") |
  | Toss | **Toss**, shown only while carrying |
  | Poop | **Poop** |
  | Hawk-eye, Caw / Flock / Pigeon | 👁 button and the ability buttons (with cooldown fill) on the right |
  | Skills & looks, Options, Sound, Restart, Extras, Speedrun, Credits, Skip tips | **☰** menu (pauses the game) |
- **Phone HUD:** compact to-do note (tap it to expand), keyboard hints and debug readouts hidden, tips at the bottom with touch wording, panels that fit about 340 px of height, scroll if needed and close by tapping (Close button, tap credits, tap the level-complete card), notch-safe margins.
- **Mobile defaults:** first visit on a phone starts on the low graphics preset (no shadow map) at up to 1.5× pixel ratio, view distance 650 m instead of 1500 m. Options can switch to high.
- **Browser quirks:** no page scrolling, zoom, text selection or long-press menu while playing; a "turn your phone sideways" card in portrait; fullscreen + landscape lock on Play where the browser allows (Android); a web-app manifest and icons for Add to Home Screen; audio starts on the first touch; held buttons are released when the tab is hidden.
- Tuning: `touch.*` (stick radius, dead zone, look speed, dive-aim slide, stick zone) in F3 on desktop with `?touch`.
- Tests: `tests/unit/touch.test.ts` (stick maths, touch detection, grab label, virtual input), `tests/smoke/touch.spec.ts` (stick walks, Flap takes off, ☰ → Skills → Close).

## Known limits
- iPhone Safari cannot lock orientation or go fullscreen for a web page: use the rotate card, or Add to Home Screen.
- Real-phone speed is unmeasured (emulation only checks layout and touch). If it stutters, try lowering Options › Screen shake and staying on the low preset, and tell me the phone model.
- The camera does not swing back behind the gull on its own; drag to look. If that is tiring we can add an auto-camera.

## Exit criteria
- [ ] Play a quest start to finish on your phone in landscape
- [ ] Controls feel usable (stick, Flap, Dive aim, Grab, Poop)
- [ ] Frame rate acceptable on your phone
- [ ] Desktop keyboard/mouse play unchanged
